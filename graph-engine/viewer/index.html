Cloud Cost Management, as a graph

A cloud-resource inventory joined to a separate billing dataset — the join is a real edge in the graph, not a runtime SQL join. This page is served by graph-viewer-server and calls it over HTTP to run your query against a live graph-coordinator, the same one query-client talks to — no query logic runs in this browser. Pipeline

ingest-cloud-cost writes this dataset into a persistent Iceberg catalog.
graph-partition-node builds the CSR + property index from it.
graph-coordinator plans and executes the query above over gRPC.
query-client streams back the matching nodes.
